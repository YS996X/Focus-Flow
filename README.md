
# Focus Flow 🕒

Focus Flow is a productivity tool designed to help users manage their time efficiently using techniques like Pomodoro, task tracking, and project organization.

## Installation

1. Clone the repository:
	```sh
	git clone https://github.com/YS996X/Focus-Flow.git
	```
2. Install dependencies:
	```sh
	cd Focus-Flow
	npm install
	```
3. Start the development server:
	```sh
	npm run dev
	```

## Configuration

If you want to use Firebase or any API features, you must provide your own credentials in the appropriate config files (see `lib/firebase.ts` and `lib/api-config.json`).
